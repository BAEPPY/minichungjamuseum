# 제공 WRL 의자 변환

현재 의자는 사용자가 제공한 `image_2026-11-01.zip` 안의 `청자투각죽문걸상(3000740).wrl`을 직접 변환한 자료입니다. 사진을 보고 수동으로 만든 이전 모델은 기본 자료에서 제거했습니다. ZIP의 다른 AI 문양 파일은 사용하지 않습니다.

VRML2 파일에는 정점 388,424개, 삼각형 777,108개와 같은 수의 정점별 RGB가 있습니다. 모든 정점과 삼각형을 유지합니다. 형태 보정·간소화·구멍 메우기·문양 재생성을 하지 않으며, 굽이 아래로 향하도록 X축으로 180도 회전합니다. 화면의 전체 크기만 공통 관찰 높이에 맞춥니다.

원본 정점 색의 색공간은 표시되지 않았습니다. 두 해석을 실제 화면에서 비교한 뒤, sRGB를 glTF의 선형 색으로 변환해 16비트 정규화 정점 색으로 저장했습니다. 원본에 없는 사진 질감이나 생성 유약 이미지는 사용하지 않습니다. 참조된 `CDI_DUK05429_1.jpg`는 제공 ZIP에 없고 텍스처 좌표도 없어 사용하지 않습니다. 웹용 유약 광택은 기본 PBR 재질로 표현하며 실측 반사율 자료가 아닙니다.

원본 ZIP·WRL 해시, 색 변환 방식, 원본 좌표·삼각형 보존 검사와 누락 파일은 `public/models/celadon-stool-wrl-source.json`에 기록합니다. 파일명에 나타나는 소장품 식별 정보만으로 원본 취득 경로나 라이선스를 확정하지 않습니다.

## 다시 만들기

Python과 NumPy가 필요합니다. 사용자 제공 ZIP에서 WRL만 추출한 뒤 실행합니다.

```sh
python scripts/convert_stool_wrl.py \
  --wrl '/path/to/청자투각죽문걸상(3000740).wrl' \
  --output public/models/celadon-stool-wrl.glb \
  --color-encoding srgb-to-linear --color-component u16
```

변환 결과 `.source.json`의 정보를 배포용 `celadon-stool-wrl-source.json`에 반영하고, 원본 ZIP의 출처 정보는 유지합니다. 변환 스크립트는 삼각형이 아닌 입력이나 원본과 다른 색 인덱스 구조를 임의로 처리하지 않고 중단합니다.
