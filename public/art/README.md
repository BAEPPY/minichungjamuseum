# 등각 박물관 이미지 자산

이 폴더의 PNG 14개는 이번 박물관을 위해 이미지 생성 도구로 각각 제작했습니다. 제공받은 ZEP 화면은 공간 배치와 등각 시점의 참고 자료이며, 해당 화면을 잘라 자산으로 사용하지 않았습니다.

| 파일 | 역할 |
| --- | --- |
| `museum-building.png` | 기와지붕 박물관 건물 |
| `museum-gate.png` | 입장 마당의 문 |
| `stone-tile.png` | 야외 돌바닥 |
| `wood-tile.png` | 실내 나무바닥 |
| `gallery-wall.png` | 실내 전시실 벽 |
| `props/display-case.png` | 유물 유리 진열장 |
| `props/tree.png` | 청자 화분의 나무 |
| `props/flower-planter.png` | 화단 |
| `props/bench.png` | 벤치 |
| `props/video-screen.png` | 제작 영상 스크린 |
| `props/writing-desk.png` | 보고서 책상 |
| `props/report-frame.png` | 학생 보고서 전시판 |
| `sprites/avatar-short.png` | 짧은 머리 아바타 동작 시트 |
| `sprites/avatar-bob.png` | 단발머리 아바타 동작 시트 |

아바타 시트는 4열 × 3행이며 앞·뒤·옆 방향과 걷기 프레임을 포함합니다. 프로그램에서 각 셀의 투명 여백을 정리하고, 탐험복 부분만 크림·초록·보라 3색으로 표시합니다. 생성된 원본 PNG는 보존합니다.

건물·가구·진열장의 각 면과 높이는 `src/projection.js`의 공통 2:1 등각 좌표에서 구성합니다. 생성한 PNG는 면 안쪽의 나무·돌·기와 질감과 장식으로 사용합니다. 지붕선, 유리벽, 받침대, 의자판, 책상, 화단의 경계는 같은 좌표 기준으로 그립니다. 렌더러는 `architecture-surfaces.js`, `display-surfaces.js`, `furniture-surfaces.js`에 나뉘며 `surface-sprite.js`가 면에 질감을 붙여 캐시합니다. 나무와 아바타는 원래 그림을 사용합니다.

마루와 포장의 이음선도 같은 등각 좌표에서 그리며 원본 타일 속의 비뚤어진 이음선을 반복하지 않습니다. 유물 미리보기의 3D 카메라는 방위각 45도·고도 30도로 맞춥니다. 모델의 실제 바닥 중심을 진열장 바닥에 놓고, 베개는 원본 사진에서 배경을 제거한 지도용 미리보기를 사용합니다. 일본 매병도 재현 모델의 등각 미리보기를 사용하며, 모델 로딩 실패 시 투명 사진으로 대신 표시합니다. 보고서의 내용도 전시판의 실제 면에 붙입니다. 자산을 교체할 때는 원본 질감의 면과 유리·화면·종이의 연결점도 함께 확인해야 합니다.

진열장 안의 매병·향로·주전자·의자·원나라 병은 제공 3D 자료의 미리보기를 사용합니다. 베개와 일본 매병의 투명 사진은 지도에서만 사용하며, 관찰·촬영은 각 작품의 실제 관찰 자료로 이어집니다. 게시한 보고서의 실제 사진을 전시판 안에 표시합니다.

`previews/japan-peony-cutout.png`는 일본 매병의 원본 `public/models/japan-peony/2_4.jpg`를 이미지 편집 도구로 배경 제거한 파생 이미지입니다. 원본과 파생 이미지의 해시 및 사용 범위는 같은 폴더의 `japan-peony-cutout-source.json`에 기록합니다. 원본 다각도 사진 54장은 관찰·보고서용으로 별도 보관합니다.
