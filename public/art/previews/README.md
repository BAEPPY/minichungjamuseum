# 베개 미리보기

`celadon-pillow-cutout.png`는 사용자 제공 SWF에서 추출한 `public/models/celadon-pillow/C05.jpg`를 참조해 이미지 생성 도구로 배경을 제거한 맵 전용 미리보기입니다. 실물 기록이나 측정 자료로 사용하지 않습니다.

이 PNG는 맵 미리보기에만 사용합니다. 관찰 창에서는 사진 기반 3D 재현과 원본 사진 54장을 선택할 수 있으며, 촬영은 선택한 관찰 모드의 화면을 사용합니다. 원본 사진 모드의 JPEG는 재인코딩하지 않았고 기존 해시 기록도 유지합니다. 3D 재현의 형상·질감 변환은 별도 출처 기록에 구분합니다.
