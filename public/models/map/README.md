# 맵 전용 3D 모델

이 폴더는 캐릭터가 이동하는 지도에만 사용하는 경량 파생 모델입니다. `/models/`의 상세 관찰용 원본 GLB는 수정하지 않았으며, 관찰창·사진 촬영·보고서는 기존 상세 모델을 사용합니다.

`blender --background --python scripts/build_map_models.py -- /path/to/repository`로 다시 생성할 수 있습니다. Blender 4.3.2에서 면 수를 작품별 약 1.4만~3.2만 개로 줄이고, 기존 질감은 최대 512픽셀 JPEG로 축소했습니다. UV·재질·정점 색·작품 배치는 유지하며 새 문양을 만들거나 색을 덧칠하지 않습니다. 실제 출력 크기·면 수와 원본/결과 SHA-256은 `manifest.json`에 기록했습니다.

일본 모란무늬 매병·베개·기존 매병 등 사진 참고 재현 자료의 추정 범위는 상세 원본의 출처 기록과 같습니다. 원나라 병의 CC BY-NC-SA 4.0을 포함해 각 원본 자료의 출처와 이용 조건도 그대로 적용됩니다. 지도용 경량화를 실측 정확도나 상세 관찰의 근거로 사용하지 않습니다.

맵은 WebGL 렌더러 하나로 가장 가까운 작품만 연속 회전시킵니다. 다른 전시대는 마지막 3D 렌더를 재사용하며, 화면 밖 모델은 GPU에서 해제하고 작은 미리보기만 남깁니다. 동시에 상주하는 모델은 최대 4개, 다운로드·해석은 한 번에 1개입니다. 관찰창·메뉴를 열거나 탭이 숨겨지면 맵 렌더를 멈춥니다.
