## 매병 · 사용자 제공 GLB

`celadon-maebyeong-v2.glb`는 `청자매병-실물질감-v2.glb`의 원본 복사본입니다. 원본 PBR 재질과 4K 색상·2K 법선/거칠기 이미지를 유지하고, 참고 녹색을 덧칠하지 않습니다.

파일 자체의 설명에 따르면 사진을 참고한 재현이며, 보이지 않는 면은 근사한 것으로 실측 스캔이 아닙니다. 모델 내부 출처: https://firefoxcat.booth.pm/items/6118090

원본 자료의 이용 조건을 따르며 이 프로젝트는 새로운 이용허락을 부여하지 않습니다.

## 베개 · 다각도 사진

`celadon-pillow/`의 54개 JPEG는 사용자 제공 `청자베개-기본화질개선.swf`에서 정적으로 추출한 이미지입니다. 이미지 내용을 재인코딩하지 않았으며, 복사본 모두 추출 원본과 SHA-256이 같습니다. 6행 × 9열의 원본 사진 이름을 유지합니다. SWF 또는 ActionScript는 배포하지 않습니다.

사진 시점을 바꿔 관찰하는 자료이며 실측 3D 메시가 아닙니다. 정확한 촬영 각도는 제공 파일에 기록되어 있지 않습니다. 원본 자료의 이용 조건을 따르며 이 프로젝트가 새로운 이용허락을 부여하지 않습니다.
