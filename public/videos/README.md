# 청자 제작 수업 영상

`celadon-inlay.mp4`는 사용자가 첨부한 `[청자실] 상감청자는 어떻게 만들까？ [YM7FhGcR_5E].mp4`를 이 사이트에서 직접 재생하는 파일입니다. 재생 화면 아래에 영상 제목과 [원본 YouTube 링크](https://www.youtube.com/watch?v=YM7FhGcR_5E)를 표시합니다. 별도 YouTube 재생기나 API 연결을 사용하지 않습니다.

영상은 약 132.26초, 1920×1080 H.264이며 음성은 AAC 44.1kHz 스테레오입니다. FFmpeg의 `-c copy -movflags +faststart`로 MP4 인덱스의 위치만 정리했습니다. 영상·음성은 다시 인코딩하지 않았으며, 원본과 결과물의 압축 스트림 SHA-256이 같습니다. 원본·배포 파일 해시와 처리 내용은 `celadon-inlay-source.json`에 기록했습니다.

학습 완료는 영상 재생 종료와 실제로 재생된 구간 90% 이상을 함께 확인합니다. 일시정지 시간이나 건너뛴 구간은 시청으로 계산하지 않습니다. 단순히 재생 위치를 끝으로 옮기는 동작만으로는 작품 관찰이 열리지 않습니다.
