# 우리들의 청자박물관 · 탐험 게임

ZEP처럼 **화면 전체의 등각 맵에서 픽셀 아바타를 움직이는 개인 탐험 웹게임**입니다. 입장 마당, 제작 영상관, 청자 전시실, 보고서 책상, 출구와 야외 보고서 전시대가 하나의 공간에 있습니다. 설명과 글쓰기는 게임 위의 창으로 열립니다.

맵은 **JavaScript + Canvas 2D**, 유물의 확대 관찰은 **Three.js(WebGL)**입니다. Python 또는 Unity 프로젝트가 아닙니다. 건물·입구·바닥·벽·진열장·식물·가구·캐릭터는 이미지 생성 도구로 개별 제작한 PNG를 사용합니다. 자산 목록은 [public/art/README.md](public/art/README.md)에 있습니다. GitHub 저장소를 Vercel에 연결해 웹 브라우저로 실행할 수 있습니다. **Sites는 사용하지 않습니다.**

## 실행

Node.js 22.12 이상 또는 24 LTS 권장.

```sh
npm ci
npm run dev
```

`http://localhost:5173`에서 실행합니다. 배포 빌드는 `npm run build`, 결과 폴더는 `dist`입니다.

## 게임 조작

- 방향키 / WASD: 화면 방향을 기준으로 캐릭터 이동
- 바닥 클릭: 진열대를 피해 해당 위치로 이동
- 전시물 클릭: 가까이 걸어가기. 가까운 전시물은 다시 클릭해 관찰 가능
- **F 키 / 화면 상호작용 버튼**: 가까운 대상의 설명·관찰·보고서·전시 창 열기
- 모바일/태블릿: 화면 방향 버튼, 바닥 터치, 상호작용 버튼 사용
- 지도: 공간별 가까운 위치로 이동. 박물관 입장·퇴장 단계는 유지
- 수첩: 유물별 사진·메모 확인, 보고서 이어 쓰기
- 캐릭터: 닉네임, 탐험복 색 3개, 머리 모양 2개 중 선택
- 확대/축소: 맵의 카메라 배율 조절. 카메라는 캐릭터를 따라감

## 관람 흐름

전시 순서는 다음과 같습니다.

1. **청자 상감 모란·구름·학무늬 베개** — 제공 SWF에서 추출한 54시점 사진으로 회전·확대 관찰. 맵에는 배경을 제거한 별도 미리보기를 사용합니다.
2. **청자 투각 의자** — 원본 GLB 등록 대기. 사용자가 지정한 [원본 자료 페이지](https://3dbank.xyz/viewer/embed_viewer.jsp?autoplay=true&uid=2989)는 교사용 등록 화면에서 확인합니다.
3. **청자 투각 칠보문 뚜껑 향로** — 제공 PLY에서 변환한 실제 스캔 형상.
4. **청자 상감 운학문 매병** — 제공 GLB의 원본 질감을 유지한 사진 참고 재현 모델.
5. **청자 어룡형 주전자** — 원본 GLB 등록 대기. [국립중앙박물관 원본 3D 자료](https://www.museum.go.kr/afile/fileDownloadById/31742)를 확보해 등록합니다.

1. 처음 접속하면 닉네임과 간단한 아바타를 선택합니다. 이용약관·연령 확인 줄은 표시하지 않습니다. 입구의 빛나는 원에서 F → 박물관 입장.
2. 왼쪽 **청자 제작 영상관**에서 [선생님이 제공한 YouTube 영상](https://www.youtube.com/watch?v=YM7FhGcR_5E)을 시청합니다. 재생기의 실제 종료 이벤트와 시청 구간을 확인한 뒤 작품 관찰이 열립니다. 단순 대기나 끝부분으로 건너뛰기만으로 완료되지 않습니다. 시청 완료는 이 브라우저에 저장합니다.
3. 오른쪽 전시실의 **베개·의자·향로·매병·주전자 5점** 관찰. 회전·시점 변경·확대 후 중요한 부분을 촬영하고 메모하며, 유물별 사진 3장과 기록을 따로 보관합니다. 의자·주전자는 원본 파일을 등록하면 사이트 자체 뷰어로 관찰·촬영할 수 있습니다. 자료 등록 전에는 준비 중 안내를 표시하고 촬영과 보고서 선택을 제한합니다.
4. 선택한 유물의 ‘이 청자로 보고서 쓰기’ 또는 보고서 책상에서 이름·사진, 쓰임, 관찰한 특징, 근거를 든 우수성, 당시 생활 추론을 작성합니다.
5. 5점 관찰과 보고서 완성을 확인한 뒤 출구에서 퇴장합니다. 보고서 작성 완료만으로 게시되지는 않습니다.
6. **야외 전시대에서 ‘내 보고서 전시하기’**. 보고서가 실제 맵의 전시판에 걸립니다. 전시판에 다가가 F를 누르면 읽을 수 있습니다.

전시판은 한 번에 6개이며 전시대의 ‘다음 전시판’으로 다음 묶음을 불러옵니다. 새로고침은 첫 묶음으로 돌아갑니다. 관람 단계·아바타 위치·유물별 기록·작성 중 보고서는 이 브라우저의 IndexedDB에 저장됩니다. 브라우저 저장 공간 삭제 시 사라질 수 있습니다.

영상은 YouTube 외부 재생기를 사용합니다. 학교 네트워크에서 YouTube가 차단되거나 제공자가 외부 재생을 금지하면 오류를 안내하고 관찰 잠금을 유지합니다. 다른 기기에서 자동으로 시청 완료를 공유하지 않습니다.

## 원본 3D 자료 직접 등록

설정 → **교사용 · 3D 자료 등록**에서 유물을 고르고 30MB 이하의 단일 GLB 파일을 선택합니다. 이미지와 모델 데이터가 파일 안에 함께 들어 있어야 합니다. 읽을 수 있는 3D 형상을 확인한 뒤 이 브라우저의 IndexedDB에 저장하고, 게임 미리보기·관찰·직접 촬영을 모두 교체합니다. 새로고침 후에도 등록한 자료가 유지됩니다. 이전 예시 의자·주전자에서 생긴 완료 표시는 첫 업데이트에서 정리하지만 사진·메모는 보존합니다. 실제 등록 자료를 관찰한 기록은 나중에 등록 파일을 지워도 유지합니다. 잘못된 파일은 기존 자료를 바꾸지 않으며, ‘등록한 파일 지우기’로 기본 자료로 돌아갑니다.

이 등록 기능은 **이 기기에서 확인하는 기능**입니다. 다른 학생 기기에 자동 배포하지 않습니다. 학급 전체에 사용하려면 최종 GLB를 `public/models/`에 추가하고 `src/artifacts.js`에서 연결해 GitHub/Vercel로 배포합니다. 파일이나 브라우저 저장 공간을 지우면 이 기기에 등록한 모델은 사라집니다.

투각 의자와 어룡형 주전자는 원본 모델을 확보하기 전까지 일반 예시 모형으로 대신하지 않습니다. 해당 전시대는 준비 중 표시를 사용합니다. 원본 뷰어의 HTML 주소 자체는 모델 파일이 아닙니다. 이 두 작품에 외부 iframe을 삽입하지 않으며, 교사용 등록 화면에 원본 페이지·다운로드 링크를 제공합니다. 베개는 기존 원본 54시점 사진을 사이트 내부에서 직접 회전·확대·촬영합니다.

## 사용자 제공 매병 GLB

`public/models/celadon-maebyeong-v2.glb`는 업로드한 `청자매병-실물질감-v2.glb` 원본을 그대로 복사한 파일입니다(약 20MB). 파일에 포함된 4K 기본 색상, 2K 표면 법선과 거칠기 이미지 및 PBR 재질을 유지합니다. 향로용 참고 녹색을 매병에 덧입히지 않습니다. 전시실·확대 관찰·촬영·보고서에서 동일한 질감을 사용합니다.

파일 내부 설명은 **사진을 참고한 재현 모델이며, 보이지 않는 면은 근사했고 실측 스캔이 아니다**라고 명시합니다. 따라서 화면과 촬영 사진에도 ‘사진 참고 재현 모델’로 표시합니다. 실물의 정확한 계측 자료로 사용하지 않습니다. 모델에 포함된 출처 링크는 `https://firefoxcat.booth.pm/items/6118090`이며, 원본 자료의 이용 조건은 별도로 확인해야 합니다.

원본 파일의 재질·이미지를 변경하지 않았고, 게임 안에서 보이는 크기와 위치만 정규화합니다. 관찰 창을 닫을 때 그 창이 소유한 재질·텍스처만 해제하므로 다시 열어도 질감이 유지됩니다.

## 실제 향로 3D 데이터

`public/models/celadon-incense.glb`는 사용자가 제공한 `스캔_PLY.zip`의 두 부분에서 생성했습니다.

- `duk002990-001-30000_step3.ply`
- `duk002990-002-30000_step3.ply`

원본 상대 위치를 유지하고 면 수를 약 28%로 줄여, 약 3.3MB의 GLB로 변환했습니다. 원본 정점은 총 246,512개, 원본 삼각형은 총 491,623개입니다. 정밀 계측이나 보존 연구용 모델은 아닙니다.

PLY에는 RGB 속성이 있지만 거의 모두 흰색 `(255,255,255)` / `(254,254,254)`입니다. **화면의 청자색은 관찰 편의를 위한 참고 표현이며 원본 색상의 복원이 아닙니다.** 관찰 창에서 원본 색상 표시로 전환할 수 있고, 촬영 사진 하단에도 표시 방식을 기록합니다.

소장품 명칭·설명 참고: [국립중앙박물관, 청자 투각 칠보무늬 향로](https://www.museum.go.kr/MUSEUM/contents/M0201020000.do?relicId=1227&schM=search). 3D 데이터는 사용자 제공 자료입니다. 공개 서비스 운영 시 **원본 3D 데이터의 이용 조건**과 필요한 출처 표기를 확인하세요. 이 저장소는 해당 데이터에 새로운 이용허락을 부여하지 않습니다.

STL은 배포물에 포함하지 않았으며 OBJ 압축파일은 실행 도구의 32MiB 전송 제한으로 확인하지 못했습니다. 제공 3D 모델은 매병과 향로이며, 베개는 다각도 사진 자료입니다. 주전자·의자는 원본 GLB를 등록하는 방식이며, 원본 등록 전에는 준비 중 표시를 사용합니다. ZEP의 맵·캐릭터·그래픽 자산을 복제하지 않고 직접 공간과 기물을 구성했습니다.

재변환(Blender 4.3 이상):

```sh
blender -b --python scripts/convert_model.py -- /path/to/extracted-ply-files
```

이 Python 스크립트는 개발 중 모델 변환용이며 게임 실행에는 사용하지 않습니다.

## 베개 · SWF에서 추출한 다각도 사진

업로드한 `청자베개-기본화질개선.swf`는 실측 3D 메시가 아니라 ObjectVR 방식의 사진 관찰 자료입니다. 파일을 정적으로 분석하여 54장의 서로 다른 JPEG 사진을 추출했습니다. 108개 이미지 항목 중 Small/Large 두 클래스는 같은 사진을 중복 포함하고 있었습니다.

- 위치: `public/models/celadon-pillow/`
- 원본 이름: `A01.jpg`~`F09.jpg` (6행 × 9열)
- 해상도: 각 1535×1183, 전체 약 8.25MB
- 추출한 사진은 다시 인코딩하지 않았으며, 54개 모두 SWF 안의 JPEG 바이트와 SHA-256이 같습니다.
- SWF 파일이나 ActionScript는 배포물에 포함하지 않습니다.
- 기본 시점·전시실 사진: `C05.jpg`.
- 원본 참조 링크: 사용자가 지정한 [국립중앙박물관 베개 뷰어](https://www.museum.go.kr/relic3D/3D/2-duk000375-000-01.html).
- 맵 전용 미리보기: `public/art/previews/celadon-pillow-cutout.png`. 이미지 생성 도구로 배경을 제거한 가공 이미지이며, 관찰·보고서 촬영에는 원본 54장의 사진을 사용합니다.

관찰 창에서 확대 전에는 끌어서 좌우·상하의 사진 시점을 바꾸고, 확대 후에는 끌어서 사진의 위치를 움직입니다. 휠/두 손가락 또는 확대 버튼을 사용할 수 있습니다. 캔버스에 초점을 맞추면 방향키로 사진 변경, +/-로 확대/축소, Home으로 초기화도 가능합니다. 화면에 실제로 표시된 사진과 확대 영역을 그대로 촬영해 보고서에 담습니다.

원본에는 각 사진의 정확한 촬영 각도가 기록되어 있지 않으므로, ‘보정된 360도 3D 모델’ 대신 **다각도 사진 자료**로 표시합니다. 게임 진열대에는 배경을 제거한 미리보기를 놓고, 관찰 창에서는 원본 사진을 사용합니다. 사진 뷰어는 전체 54장을 한 번에 메모리에 올리지 않고 최근 사진만 보관합니다.

## GitHub → Vercel

대상 저장소: `BAEPPY/minichungjamuseum`.

1. 프로젝트를 GitHub에 업로드합니다. `node_modules`, `dist`, `.env`, `.vercel`은 제외합니다.
2. [Vercel New Project](https://vercel.com/new)에서 저장소를 Import합니다.
3. Framework: **Vite**, Root Directory: 저장소 루트, Node.js: **24.x** 권장.
4. Install: `npm ci`, Build: `npm run build`, Output: `dist`.
5. `vercel.json`에 빌드 설정이 포함되어 있습니다. Git 연결 후 브랜치 push마다 Vercel 배포를 사용할 수 있습니다.

기본 개인 체험에는 환경변수가 필요 없습니다. `api/reports.js`는 Vercel 서버리스 함수입니다. 로컬 Vite만 실행하면 API가 실행되지 않아 이 기기 모드로 동작합니다. 로컬 API 테스트가 필요하면 Vercel CLI 프로젝트 연결 후 `vercel env pull .env.local`, `vercel dev`를 사용합니다.

## 다른 기기와 보고서 공유(선택)

기본은 **이 브라우저에서 저장·전시하는 개인 체험**입니다. 친구 기기의 보고서까지 함께 전시하려면:

1. Vercel 프로젝트의 Marketplace에서 **Upstash Redis**를 연결합니다. 요금·약관은 해당 서비스에서 확인합니다.
2. Marketplace가 자동 등록한 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 두 항목이 있으면 그대로 사용할 수 있습니다. 직접 설정한 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 조합도 지원합니다. 두 조합이 모두 있으면 완전한 `UPSTASH_*` 조합을 우선하며, 서로 다른 조합의 주소와 토큰을 섞지 않습니다. 환경변수 설정 후 재배포합니다. `VITE_` 접두사를 붙이거나 토큰을 코드·GitHub에 넣지 않습니다. `KV_REST_API_READ_ONLY_TOKEN`과 `REDIS_URL`은 보고서 저장 연결에 사용하지 않습니다.
3. 교사가 충분히 긴 임의의 전시실 코드를 배포합니다(영문·숫자·하이픈 12~48자). 학생들은 게임 우측 상단 설정에서 같은 코드를 입력합니다.
4. 이후 게시하는 보고서가 공유됩니다. 기존 로컬 보고서를 자동 업로드하지 않습니다.
5. 야외 전시대에서 친구 보고서 새로고침/다음 전시판으로 읽습니다. 최대 200개를 목록에 유지하고 각 보고서는 30일 후 만료됩니다. 필요한 결과물은 읽기 창의 인쇄/PDF 또는 설정의 로컬 보고서 JSON 내보내기로 보관합니다.

이것은 접근 코드를 공유하는 시제품입니다. 학생별 로그인·교사 승인·게시물 삭제 관리·실시간 공동 접속은 포함하지 않습니다. 전시실 코드를 아는 사람은 해당 전시실의 보고서를 읽고 게시할 수 있으므로 실제 학급 운영에는 학교 정책에 맞는 인증과 관리 기능을 추가해야 합니다. 별명 사용을 권장합니다. **다른 친구의 아바타·음성·채팅은 실시간으로 보이지 않습니다.**

브라우저 테스트는 `/usr/bin/chromium`을 기본으로 사용합니다. 다른 경로는 `CHROMIUM_PATH`로 지정합니다. 닉네임 필수 입력과 최소 꾸미기, 영상 시청 전 잠금과 시청 완료 후 관찰, 실제 향로 촬영 → 보고서 작성 → 퇴장 → 맵의 전시판 게시·읽기, 위치와 메모 복원, 모바일 터치 상호작용을 검사합니다. 매병 테스트는 원본 PBR 질감·색상·재질 값, 텍스처 소유권, 재열기와 촬영/보고서 삽입을 확인합니다. 베개 테스트는 사진 시점 변경·확대·촬영·기록 복원을 확인합니다. 공유 API 입력 검증과 저장소 미설정 응답도 검사합니다.

자동 테스트의 YouTube API는 대역으로 제공합니다. 영상의 실제 공개 상태·외부 재생 허용은 자동 테스트로 보증하지 않습니다. 의자·주전자 슬롯의 네이티브 로딩 테스트에는 별도로 표시한 시험용 GLB를 사용하며, 이 시험 모형을 해당 유물의 실물 자료로 배포하지 않습니다. 실제 Upstash 연결 검증은 환경변수 설정 후 필요합니다.
